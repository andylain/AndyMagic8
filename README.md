# AndyMagic8

🎱 神奇八號球 —— 一顆球，多種抽籤模式。零相依、可離線使用。

線上版：<https://andylain.github.io/AndyMagic8/>

## 使用方式

點一下球（或按 Enter／空白鍵）搖出答案。左上角選單切換模式，右上角開關音效（預設靜音）。
選單最下方另有「安裝」（瀏覽器支援時才出現）與「關於作者」。

## 模式

| 模式 | 題數 | 說明 |
| --- | --- | --- |
| 🎱 神奇八號球 | 20 | 預設模式。肯定 10、否定 5、模稜兩可 5 |
| 🍽️ 今天吃什麼 | 100 | 小吃／麵食／飯類／異國／清爽 |
| 🌍 吃哪一國料理 | 50 | 亞洲／歐洲／美洲／非洲／中東 |
| 🧋 喝什麼飲料 | 100 | 茶飲／咖啡／無糖／其他 |
| 🌙 吃什麼宵夜 | 100 | 鹹食／麵食／異國／清爽／甜食 |
| 🎭 抽個懲罰 | 30 | 表演／動作／說話／任務／搞怪，闔家歡樂 |
| 🎲 擲骰子 | 6 | ⚀–⚅ |
| 🔢 0～100 猜數字 | 101 | 用 `roll()` 算出來，不列清單 |
| ⚖️ Yes or No | 2 | |
| 🧭 往哪走 | 8 | 前後左右八個方向 |

八號球、骰子、Yes or No、方向、數字都是每次獨立隨機，不記上一次抽到什麼。
食物、料理、飲料、宵夜、懲罰會避開連續抽到同一項（`noRepeat`）。
App 每次開啟都回到八號球，不會記住上次用的模式。

## 檔案

```
index.html    只有結構
styles.css    樣式
modes.js      模式與清單資料 ← 要加新模式改這裡就好
app.js        應用邏輯
sw.js         Service Worker，離線快取
manifest.json PWA 設定
*.png         各平台圖示
```

## 新增模式

只要在 `modes.js` 的 `MODES` 陣列推一筆，選單、標題、字級、配色都會自動跟上：

```js
{
  id: "xxx", icon: "🎯", label: "選單上的名稱", size: "md",
  hint: "球下方的提示文字",
  initial: { primary: "?", secondary: "點一下球" },
  noRepeat: true,
  items: [
    { primary: "大字", secondary: "小字", tone: "snack" }
  ]
}
```

- `size`：`md`（詞彙）、`lg`（YES/NO）、`xl`（單一符號或數字）；省略則用預設字級
- `tone`：對應 `modes.js` 最上方的 `TONES`，新顏色也加在那裡；省略則用預設白色
- `noRepeat`：避開連續抽到同一項。清單長度 ≤ 2 時自動忽略，否則「隨機」會變成「輪流」

選項太多不適合列成清單時，改用 `roll()` 直接算：

```js
roll: () => ({ primary: String(Math.floor(Math.random() * 101)), secondary: "0 – 100" })
```

有 `roll()` 就不需要 `items`（`noRepeat` 也不適用）。

## 離線支援

`sw.js` 在首次載入時快取整個 App，之後完全不需要網路。

- **HTML／CSS／JS 走 network-first** —— 有網路時一律拿最新版，快取只是離線後備。
  三者必須一起，只要有一支吃到舊快取、配上新的另一支，畫面就可能壞掉
- **圖示與 manifest 走 cache-first** —— 不常變動，直接吃快取
- 改動較大時把 `sw.js` 的 `VERSION` 換掉，舊快取會整包清除

改版後通常要重整兩次才看得到：第一次載入時舊的 Service Worker 還在服役，
抓到新檔案後要下一次載入才生效。這是正常行為。
