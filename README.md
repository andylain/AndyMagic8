# AndyMagic8

🎱 神奇八號球 —— 一顆球，多種抽籤模式。零相依、可離線使用。

線上版：<https://andylain.github.io/AndyMagic8/>

## 使用方式

點一下球（或按 Enter／空白鍵）搖出答案，**手機也可以直接甩動手機**。
右上角搖過之後會出現 📤 分享、📋 開啟目前模式的總表、🔊 開關音效（預設開啟，關掉會記住）。
左上角選單切換模式，最下方有「搖一搖」開關、「安裝」與「關於作者」。

- **搖一搖**：Android 預設開啟；iOS 需要在選單裡按一次授權動作感測。門檻訂得夠高，
  走路或放口袋不會誤觸，冷卻 1.2 秒避免一次甩動連開好幾槍
- **震動回饋**：搖動時震一下（`navigator.vibrate`，iOS 不支援）。
  系統開了「減少動態效果」時連震動也一起省略
- **分享**：優先用系統原生分享選單，不支援時退回複製到剪貼簿
- **iOS 安裝**：Safari 沒有安裝提示的 API，選單會改成顯示「加入主畫面」的操作指引

八號球、運勢以外的抽籤模式各有取捨：

- **不記上一次**：八號球、骰子、Yes or No、方向、數字、撲克牌 —— 每次都必須獨立隨機
- **避開連抽重複**（`noRepeat`）：吃喝、穿搭、顏色、電影、交通、運動、懲罰
- **加權**：預算模式常見價位權重高，1000 元以下佔約 78%，越貴越少出現
- **色塊**：選一個顏色會在答案上方顯示真實色票，純黑、藏青這種深色才看得見
- **長項目自動縮字**：超過 6 個字的項目會降一級字級，免得貼到視窗邊緣
- **流動背景**：六團彩光用 `mix-blend-mode: screen` 互相疊亮（不是單純堆疊），
  12～21 秒的首尾相接循環讓它們四處遊走。刻意不用 `filter: blur()` —— 大面積模糊在手機上很貴，
  漸層本身的柔邊就夠了。下緣有一層暗場，否則提示文字與 footer 的對比度會掉到 2.5 以下
- **玻璃罩**：文字上方蓋一層 CSS 玻璃（頂緣高光弧、左上斜向反光、內緣厚度陰影）。
  刻意不用 `backdrop-filter`，那會把文字一起糊掉；反光偏左上，避開正中央的文字

麥當勞的品項以常見的台灣菜單為準。速食菜單會改版，發現有品項下架或想加新品，
直接編輯 `modes.js` 裡 `id: "mcd"` 那一段就好。

兩個旅遊模式刻意不是同一份清單的子集。亞洲版收 56 個目的地，涵蓋到廣島、檳城、峴港
這類次級城市；世界版的亞洲只留 15 個樞紐，否則亞洲會佔掉七成以上，抽「全世界」
卻幾乎都抽到亞洲。機場代碼是人工整理的，可能有過時的（例如暹粒 2023 年換了新機場）。

App 每次開啟都回到八號球，不會記住上次用的模式。

右上角 📋 可以打開目前模式的完整清單；用 `roll()` 算出來的模式（預算、數字、撲克牌）
沒有固定清單，改顯示 `summary` 的範圍說明。

## 社群分享

`index.html` 的 `<head>` 有 Open Graph、Twitter Card 與 JSON-LD 結構化資料，
預覽圖是 `og.png`（1200×630，Facebook 建議尺寸）。

**換網域時**要一起改：`canonical`、`og:url`、`og:image`、`twitter:image` 四個絕對網址，
以及 JSON-LD 裡的 `url`。`check.js` 會驗證 `og:url` 與 `canonical` 一致、
`og:image` 是絕對網址、宣告的尺寸與實際檔案相符。

**部署後記得去 [Facebook 分享偵錯工具](https://developers.facebook.com/tools/debug/)**
貼上網址按「Scrape Again」，否則 Facebook 會一直顯示舊的快取。

分享描述刻意不寫模式數量，這樣新增模式時不用改文案。圖片上的數量則是
`make-og.js` 從 `modes.js` 讀出來的，重跑就會更新。

## 開發

```
node check.js      驗證資料與版本一致性（CI 每次 push 都會跑）
node bump.js       資源版本號 +1，三個地方一起改
node bump.js 12    指定版本號
node make-og.js    重新產生社群分享預覽圖（需要 npm i playwright-core）
```

`check.js` 會擋下：清單重複、未定義的 tone、同模式內兩個分類撞色、
過長而會排版變醜的項目、非正數的權重、多打逗號造成的陣列空洞、
版本號沒同步、以及 `sw.js` 漏掉預快取的檔案。改完 `modes.js` 先跑一次它。

## 檔案

```

```

## 新增模式

只要在 `modes.js` 的 `MODES` 陣列推一筆，選單、標題、字級、配色都會自動跟上：

```js
{
  id: "xxx", icon: "🎯", label: "選單上的名稱", size: "md",
  hint: "球下方的提示文字",
  initial: { primary: "?", secondary: "點一下球" },
  noRepeat: true,
  items: [
    { primary: "大字", secondary: "小字", tone: "snack" }
  ]
}
```

- `size`：`md`（詞彙）、`lg`（YES/NO）、`xl`（單一符號或數字）；省略則用預設字級
- `tone`：對應 `modes.js` 最上方的 `TONES`，新顏色也加在那裡；省略則用預設白色
- `weight`：抽中的相對權重，省略等於 1。整份清單都沒寫就走均等隨機的快路徑
- `noRepeat`：避開連續抽到同一項。清單長度 ≤ 2 時自動忽略，否則「隨機」會變成「輪流」

選項太多不適合列成清單時，改用 `roll()` 直接算：

```js
roll: () => ({ primary: String(Math.floor(Math.random() * 101)), secondary: "0 – 100" })
```

有 `roll()` 就不需要 `items`（`noRepeat` 也不適用）。

## 離線支援

`sw.js` 在首次載入時快取整個 App，之後完全不需要網路。

- **HTML／CSS／JS 走 network-first** —— 有網路時一律拿最新版，快取只是離線後備。
  三者必須一起，只要有一支吃到舊快取、配上新的另一支，畫面就可能壞掉
- **圖示與 manifest 走 cache-first** —— 不常變動，直接吃快取
- 改動較大時把 `sw.js` 的 `VERSION` 與 `ASSET_V` 一起換掉，並同步更新 `index.html`
  裡 `?v=` 的值。`index.html` 一律走網路，所以新的版本號一定拿得到，
  帶版本的網址會產生新的快取鍵 —— 就算使用者裝的是還沒換代的舊 Service Worker，
  也不會被它的 cache-first 卡住舊的 CSS/JS

改版後通常要重整兩次才看得到：第一次載入時舊的 Service Worker 還在服役，
抓到新檔案後要下一次載入才生效。這是正常行為。
